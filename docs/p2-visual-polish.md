## 本轮改动

### P2-1 充电塔底环脉冲

`chargingTowerModel.ts` 在静态地面光斑之上新增贴地发光圆环（内径 0.85m / 外径 1.05m，环抱 0.74m 塔基，抬升 0.007m 避开光斑共面）。环材质为加法混合无光照贴花，复合两段既有 shader 注入（`semanticMaterials.ts`）：

- **投影尺寸淡出**：投影小于 8px 开始淡出、2.5px 完全隐藏——59 处充电设施在总览同步隐没，不变成排闪烁光源（8.4 密度约束）；
- **亮度脉冲**：2.4s 正弦周期、最暗 0.35，只在近中景可感。

淡出作用于 alpha、脉冲调制 rgb，互不干扰；uniform（视口高度、时间）由 `ChargingTowersLayer` 的 `useFrame` 逐帧写入，纯 GPU 完成、无逐帧 CPU 几何/矩阵改写。环不进地坪倒影（无光照贴花在反射采集时隐藏）、不投影、参与既有释放链。

### P2-2 停车 P 字母恢复

`LandmarksLayer.tsx` 消费 Feature 持有的名称图集（`PARK_GLYPH_KEY` 单元格），把停车锚点烘焙为贴地合批四边形：世界高 1m、沿 +z 偏移 0.2m 让 P 完整落在 slab 前半幅、`NAME_QUAD_Y` 高度避开全部贴花顶端，30–70m 距离淡出。图集缺失（无 Canvas 环境）时优雅降级为仅 slab，绝不悬空引用 UV 区域；本组件只释放几何与材质，图集纹理仍归 Feature 所有。

### P2-6 背景轻暗角

`BACKGROUND_VIGNETTE_STRENGTH` 0 → 0.12：高位总览时四角轻微压暗提供聚焦感；浅灰背景下刻意保持轻量，不复现暗色主题的黑色暗角。
