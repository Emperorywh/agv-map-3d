# 厂房空间效果升级

本轮修改直接接入真实地图，重点是浅灰涂层地坪、厂房内墙和二者的光照关系。使用 Three.js 程序化建筑，没有新增 Blender 模型或外部贴图。

## 已实现

- **空间尺度**：建筑余量按通行和检修需求控制在每侧 12～16 米，再对齐 8 米柱网，减少大地图外围的空地。
- **地坪材质**：降低颗粒、磨损和分缝对比，加入墙根接触明暗以及墙脚柔光过渡。真实墙体和车辆通过镜像相机形成模糊倒影。
- **墙面构件**：每跨六块墙板，配合倒角立柱、柱脚、低位灯槽、高窗和卷帘门；构件按材质与剖切层合批。近侧上墙随视角隐藏，墙脚保留边界。
- **光照与阴影**：环境贴图加入顶部条形柔光；主光方向固定，阴影范围优先覆盖当前观察区域，以改善近景接触感。
- **镜头**：默认俯角为 38°，画面上沿允许落在墙面。缩远时连续转向高位总览；60°～75°逐渐放宽画面边缘，允许展示厂房外轮廓并完整容纳地图。

## 查看与验收

启动 `pnpm dev` 后：

- 真实地图：`http://localhost:5173/`
- 空间样板：`http://localhost:5173/?assets=factory`

空间样板仅在开发环境启用，复用正式地坪、墙体和灯光，提供“空间样板 / 墙脚近景 / 地坪倒影 / 高位总览”四个固定机位。灰色体块只是阴影和反射的参照物，不进入真实地图。右上角显示帧率及存活几何、纹理数量；可重建资源，检查释放是否对称。反射始终开启，预览不提供低画质切换。

## 性能与实现边界

平面反射以 1024 × 1024 分辨率逐帧采集镜像场景，静止和移动镜头采用相同更新节奏。倒影使用预过滤纹理，每个地坪像素只采样一次；业务标签、节点和无光照贴花不进入倒影。

项目已删除自动画质模块、帧率采样状态机及全部下游降级开关。所有环境始终启用完整反射、动态阴影、标签候选预算和呼吸动画；阴影分辨率直接使用 `renderer.shadowMapSize`，DPR 使用设备像素比与 `renderer.maxDpr` 中的较小值，运行负载不会降低这些参数。实际帧率取决于视口、车辆数量及硬件，样板帧率不能代替真实地图性能。

墙脚柔光和墙板遮蔽是程序化近似；本轮没有烘焙全局光照，也没有引入全屏环境遮蔽。参考图的离线渲染质感仍可通过后续局部烘焙进一步提升。

## 检查命令

```sh
pnpm verify:space
pnpm verify:roads
pnpm typecheck
pnpm lint
pnpm build
```

空间回归验证真实地图边界、横竖屏全图总览、相机射线与墙地求交、贴边跟随净空、反射异常后的显隐恢复、卸载回调恢复，以及静止相机连续帧的反射采集与完整渲染目标尺寸。道路检查继续使用已有回归脚本。

地坪与反射在同一个副作用中创建和释放，严格模式重挂时始终取得新的句柄；卸载先恢复反射回调再释放地坪材质。资源重建继续清理材质程序缓存，确保新材质绑定新纹理。
