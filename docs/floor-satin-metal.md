# 深蓝灰缎面金属地板验收

2026-09-09。目标更新为深蓝灰缎面金属，只改地面、地面环境及既有反射配置。业务、设施布局、路线几何、相机功能、全局灯光、曝光和 Bloom 保持原值。

## 实际生效链路

用户图2是最终渲染，不是颜色贴图。运行时地面为 `MeshStandardMaterial`，使用颜色、粗糙度和法线三张程序纹理；没有金属度贴图。原金属度为 0，粗糙度材质乘子为 1、灰度图基准为 0.5，法线强度为 0.1，环境强度为 0.25，曝光为 1、色调映射为 ACES。原颜色图和数据图仍含多尺度云斑，法线高度场还有大尺度起伏。

已核对本地 Three.js 的实际 shader：粗糙度读取贴图绿色通道，与材质 roughness 相乘；金属度仅在绑定金属度贴图时乘其蓝色通道。地面的自定义 shader 保留标准 PBR，光照计算后补墙根接触明暗和低权重的实体倒影，没有覆盖金属度或粗糙度。

先关闭全部地面纹理，以 `metalness=1`、`roughness=0.35`、底色 `#7d8994` 验证既有环境反光。随后复用现有环境工厂的 PMREM 流程，为地面生成独立的暗背景和不对称宽灯箱环境；设备继续读取原有场景环境。

最终颜色图以白色为中性乘子，仅存细窄灰缝，底色由材质提供。颜色图不含高光、光源形状或场景倒影，也没有把深色底色乘算两遍。

## 最终参数

| 参数 | 最终值 |
| --- | --- |
| 材质 | `MeshStandardMaterial` |
| 底色 | `#697582`，sRGB |
| 金属度 | `1`；无金属度贴图 |
| 粗糙度 | 贴图均值 `0.3603`，实测范围 `0.3294～0.3765`；材质乘子 `1` |
| 无贴图回退粗糙度 | `0.36` |
| 法线强度 | `(0.08, 0.08)` |
| 环境强度 | `0.8`，仅地面 |
| 环境旋转 | Y 轴 `-0.4 rad`，约 `-22.9°` |
| PMREM 预模糊 | `0.04 rad` |
| 纹理 | 三张 `1024×1024`；颜色图 sRGB，粗糙度与法线为线性数据 |
| 纹理世界尺寸 | 接缝图 `12 m`；拉丝和划痕 `2 m`，细节像素约 `1.95 mm` |
| 接缝 | 间距 `6 m`；宽约 `3.05 mm`；无固定受光亮边 |
| 划痕 | 每 `2×2 m` 18 条，长 `6～28 cm`，低对比浅划痕 |
| 各向异性过滤 | 上限 `8`，受硬件能力限制 |
| 地面高度 | `-0.008 m`，沿用原值 |
| 曝光 / 色调映射 | `1` / ACES，沿用原值 |

地面环境由三块宽灯箱一次预过滤生成，线性颜色分别为 `(1, 1.08, 1.18)`、`(0.72, 0.8, 0.9)`、`(1.1, 1, 0.88)`。背景保留暗部，避免均匀环境光将地面整体提成浅灰。

## 场景倒影和成本

静态环境负责金属高光，不包含动态车辆或设备。实体倒影继续使用现有镜像相机与反射目标：均衡档 `512×512`、静止镜头最高 30 次/秒，镜头移动立即更新；沿用 mip 与九点柔化采样。混合权重由 `0.10` 到掠射极限 `0.24`，基础模糊层级 `1.35 + roughness × 0.8`。

保留原有反射排除规则和路线贴地发光表现，没有给每条路线创建灯光或独立反射通道。新增成本是一张地面专用预过滤环境纹理和创建时的一次采样，没有增加逐帧场景采集次数。地面卸载先解除反射钩子，再释放专用环境和纹理；环境生成失败时回退到既有场景环境。
