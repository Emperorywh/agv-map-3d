# 地面均匀亮度验收

2026-09-09。根据新的要求，取消随距离和观察方向出现的大面积明暗差异。本次结果替代 `floor-satin-metal.md` 中关于不对称灯箱、环境旋转及掠射角增强倒影的设置。

## 调整

- 地面独立环境改为全方向同色，颜色 `#aebac6`，强度 `1.6`，不再设置环境旋转或灯箱。
- 地面受光计算使用世界空间固定的 45° 观察方向，避免金属菲涅耳响应随真实相机旋转、平移、缩放而改变基础亮度。真实相机仍负责几何投影与实体倒影。
- 实体倒影的混合上限固定为 `0.10`，不再在低角度加深。
- 关闭场景距离雾，移除远景颜色衰减。

底色、金属度、粗糙度与法线纹理沿用现有设置。局部阴影、墙根接触着色、灯光与实体倒影仍有明暗细节；这里统一的是地面的基础照明。设备自身的材质明暗仍保留。

## 验证

在实际监控入口检查低角度、水平旋转、缩放与俯视。截图直接保存，未做后期调色。

低角度空白地面在截图坐标 `(120,160)`、`(120,650)` 的 RGB 分别为 `(89,111,135)`、`(89,111,134)`；近景空白地面 `(120,600)` 为 `(89,111,135)`。采样仅说明这些无局部光影位置的基础颜色一致，不代表路线、阴影和反射覆盖区的每个像素同色。

- `pnpm build` 通过，包含 TypeScript 和发布产物验证；保留原有包体超过 500 kB 的提示。
- `pnpm lint` 通过。
- `pnpm verify:space` 五项通过，覆盖空间取景与反射恢复。
- 完整重新加载后场景正常渲染，未捕获控制台错误。
